# Managing Inventory in the UI

The Seller Dashboard provides a user-friendly interface for managing your product listings and tracking stock levels in real-time.

## Adding Products

To add a new product, navigate to the **Inventory** tab and click the **Add Product** button. You will be prompted to fill in the following details:

{% table %}

- Field
- Description
- Required

---

- Product Name
- The public title of your item as seen by buyers.
- Yes

---

- SKU
- A unique identifier for internal tracking.
- Yes

---

- Price
- The unit cost in USD.
- Yes

---

- Initial Stock
- The number of units currently available for sale.
- Yes

---

- Category
- The marketplace department where the item will be listed.
- No

{% /table %}

## Bulk Updates

If you need to update prices or stock levels for multiple items at once, use the **Bulk Edit** feature.

1. Select the products you wish to update using the checkboxes in the inventory list.
2. Click the **Actions** dropdown and select **Bulk Edit**.
3. Apply changes to the selected fields (e.g., "Increase Price by 5%").
4. Review the changes and click **Save All**.

## Setting Up Alerts

Never run out of stock unexpectedly by configuring low-stock notifications.

You can set a threshold for each product under the **Alerts** tab in the product detail view. When the stock level drops below this number, the system will send an automated email to your registered account.

**To enable global alerts:**
1. Go to **Settings > Notifications**.
2. Toggle on **Low Stock Warnings**.
3. Set a default threshold (e.g., 5 units) that applies to all products without custom settings.
